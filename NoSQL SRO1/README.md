# Student Management System

Мини-проект СРО №1 по дисциплине **«Визуальное программирование»**
(ОП 6B06101 — Информационные системы).

**Автор:** Котов Расул, группа ИС24-22
**Тема:** №1 — Student Management System (учёт студентов)
**Технологии:** Java 17, JavaFX 21, FXML, Scene Builder, Maven

Репозиторий: _вставьте ссылку на ваш GitHub-репозиторий_

## Возможности

- Таблица студентов (`TableView`) с сортировкой по любому столбцу, 12 демонстрационных записей
- Карточка выбранного студента справа от таблицы
- Добавление, редактирование (кнопка, меню, двойной клик) и удаление (с подтверждением)
- Поиск по ФИО / e-mail, фильтры по группе и курсу, сброс фильтров
- Валидация ввода во второй форме (ФИО, группа, курс, дата рождения, e-mail, телефон)
- Статистика (количество, средний GPA, лучший студент, распределение по курсам)
- Автосохранение в CSV (`~/.student-management/students.csv`), импорт и экспорт CSV
- Повреждённые строки CSV пропускаются, приложение не падает

## Запуск

Требуется **JDK 17+** и **Maven 3.8+** (JavaFX скачивается автоматически через Maven).

```bash
git clone <ссылка-на-репозиторий>
cd student-management
mvn javafx:run
```

Запуск тестов валидации: `mvn test`

### Запуск из IntelliJ IDEA
1. `File → Open` → выбрать папку проекта (откроется как Maven-проект).
2. Подождать загрузки зависимостей.
3. Запустить `mvn javafx:run` во вкладке Maven (Plugins → javafx → javafx:run)
   либо запустить класс `kz.kotov.sms.MainApp`.

### Редактирование интерфейса в Scene Builder
Откройте файлы `src/main/resources/fxml/main.fxml` и `student-form.fxml`
в Scene Builder (`File → Open`).

## Соответствие требованиям СРО

| Требование | Реализация |
|---|---|
| FXML + отдельный Controller | `main.fxml` / `MainController`, `student-form.fxml` / `StudentFormController` |
| ≥ 2 layout и ≥ 5 типов Controls | BorderPane, VBox, HBox, GridPane; TableView, TextField, ComboBox, DatePicker, Slider, Button, Label, MenuBar, ToolBar |
| TableView, ≥ 10 записей | `TableView`, 12 демо-записей |
| Добавление, редактирование, удаление, поиск, фильтрация | Реализованы (см. «Возможности») |
| MenuBar, ToolBar, строка состояния, ≥ 2 горячих клавиш | Есть, 7 горячих клавиш |
| ≥ 2 окна, навигация, Alert | Главное окно + модальная форма; Alert: подтверждение, ошибка, предупреждение, информация |
| Проверка ввода без аварийного завершения | `Validator`, обработка `IOException` и повреждённого CSV |
| Локальное хранение CSV | `StudentRepository` |
